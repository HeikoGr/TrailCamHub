TrailCamHub · ESP32-S3

Firmware installer

Install the latest TrailCamHub BLE proof-of-concept firmware and inspect its serial logs.

Install firmware

  1. Connect your ESP32-S3 board to this computer with a USB data cable.
  2. Choose a build version and variant below, then select the board's serial port when your browser asks.
  3. Confirm the installation in the browser dialog.

 

Development build

Verbose serial logs (INFO level). Use this to watch the camera protocol and read responses in the serial console below.

Use a desktop Chromium-based browser that supports Web Serial, such as Chrome or Edge. Open this page over HTTPS and allow serial-port access in your browser.

Release build

Size-optimized, warnings-only logging. Use this for normal operation.

Use a desktop Chromium-based browser that supports Web Serial, such as Chrome or Edge. Open this page over HTTPS and allow serial-port access in your browser.

Each build is the CI firmware for the ESP32-S3 at that commit. The firmware activates and talks to a camera only where those connections are authorized.

Live protocol view

Decodes the serial log as it streams in: the camera session's progress, the parsed media list, and the raw thumbnail/photo bulk frames. Connect the serial console below to drive it live, or replay a bundled sample.

    Media list

     

    #TypeDirNummediaIdTime

    Bulk frames

    Thumbnail/photo data on the bulk channel (D0/D1 subtype 0x03/0x04). Decoded from the recon hex dump: ARTEMIS record header, 72-byte media header, JPEG start.
